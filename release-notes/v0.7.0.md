## Changes

- Preview the selected Frame Capture position before saving it.
- Navigate precisely with an editable timestamp, a position scrubber, and actual-frame step controls.
- Use the same preview and precision controls when editing Frame Capture jobs in Queue and per-file Batch overrides.
- Copy the selected full-resolution frame directly to the Windows clipboard.
