# Apollo application icon

`apollo-logo.png` is the supplied application artwork. `apollo.ico` contains 16, 24, 32, 48, 64,
128, and 256 pixel Windows icon frames derived from that PNG.

The native window embeds `apollo-logo.png`. Windows executable resources, the installer, and the
uninstaller consume `apollo.ico`; Start Menu and Installed Apps entries inherit the executable icon.
